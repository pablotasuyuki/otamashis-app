# Otamashis para Windows

Instalador do app **Otamashis** — chat, voz, vídeo e compartilhamento de tela.

**Baixar:** [otamashis.online/download](https://otamashis.online/download)

Este repositório guarda apenas os arquivos de instalação:

- `Otamashis.exe` — o instalador (o que você baixa)
- `manifest.json` e `payload.*` — o app, baixado pelo instalador em partes e conferido por SHA-256
